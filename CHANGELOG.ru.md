### 8.9
- O2 переключения: алгоритм `o2_crossing_rate` переписан с `shift(1)` на автомат состояний с гистерезисом (`check_catalyst.py`) — предыдущий подход пропускал почти все переходы при LOG_DT=1с, т.к. требовал прямого скачка из < 0.4В в > 0.6В за один шаг; теперь промежуточные значения 0.4–0.6В игнорируются, учитываются только переходы между зонами «бедная» (≤ 0.4В) и «богатая» (≥ 0.6В); фильтр замкнутого контура: только строки с COOLANT_TEMP ≥ `O2_CROSSING_MIN_COOLANT_TEMP` (70°C); длительность рассчитывается как число прогретых строк × `LOG_DT`, что корректно работает в разреженных логах
- Сравнение: добавлены 8 новых метрик во все форматы (CSV, XLS, HTML, PDF): RPM среднее, скорость средняя, нагрузка двигателя среднее, T ОЖ среднее, T впуска среднее, время впрыска среднее, O2 богатая смесь (%), O2 бедная смесь (%)
- Сравнение: метрики в сводной таблице отсортированы по смысловым группам: поездка → режим езды → температуры → топливо → воздух/MAF → O2/лямбда → детонация/заглохи → катализатор
